# specs/

Una carpeta por historia de usuario, con su `spec.md` y su `plan.md`.

| Carpeta | Unidad | Historia |
|---|---|---|
| `HU-01-listar-pedidos/` | U2 | Como vendedor, quiero listar pedidos filtrando por cliente, estado y rango de fechas. |
| `HU-03-calculo-totales/` | U5 | Como contabilidad, quiero que el portal calcule los totales igual que el legado, para migrarlos sin que ningún cliente pague un peso distinto. |

No se escribe código sin una spec aprobada (ver `AGENTS.md`).
